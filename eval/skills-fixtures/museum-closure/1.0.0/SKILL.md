# 博物馆闭馆检查

只在研究阶段使用，用于补充闭馆规则。

## 检查顺序

1. 先看候选数据里的 open_hours，明确每个博物馆的闭馆日。
2. 没有 open_hours 时，默认周一闭馆，并在 warnings 里提示出发前复核。
3. 闭馆日与行程冲突时，优先换成同区域的免费展馆或户外点位。
4. 预约制博物馆在 notes 里写明提前预约，不要假设现场可进。

不要编造开放时间；数据缺失就如实提示。
