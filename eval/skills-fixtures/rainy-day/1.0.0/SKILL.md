# 雨天替代方案

只在用户明确提到下雨、台风或高温等天气影响时使用。

## 替换原则

1. 先找同区域的室内展馆、商场或书店，避免跨区绕路。
2. 户外点位保留在 notes 里作为天气好转时的备选，不直接删除。
3. 雨天步行时间按 1.3 倍估算，并在 warnings 里提示带伞。
4. 替换后重新检查预算和闭馆日，不能因为避雨引入新的冲突。

没有室内备选时，明确告诉用户哪些点位可能受影响。
