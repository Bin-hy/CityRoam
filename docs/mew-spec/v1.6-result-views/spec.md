# TripPilot v1.6 结果页三视图 Spec

状态：已批准（spec）
日期：2026-11-20

## 背景

v1.5 把工作台改成了对话优先，但结果展示仍是「地图 + 时间轴 + 右侧检查器 + 每日列表」：地图占据主视线，时间轴是密集色块，检查器未选中时是空的。用户看到成品的第一反应是「丑、安排不够清晰」，因为页面先展示控件，而不是先讲清楚这几天怎么过。

现有数据已经够用：每天的时间、时长、花费、交通衔接、留白，住宿与预算口径，逐点解释与攻略来源，版本与分享快照。本次不新增数据，只改结果的阅读方式。

## 目标

- 结果页第一屏就能回答「这趟几天、每天怎么过、大概花多少」。
- 按天阅读时有完整叙事：时间锚点 → 地点 → 停留时长 → 交通衔接 → 为什么选它 → 攻略来源 → 当天花费；未排时段显式标注，不留空白。
- 提供手册、地图、看板三种视图，顶部一键切换；切换时天、选中点、预算口径、版本保持一致。
- 桌面与 390px 移动端都能完成同样的阅读；分享页保持只读手册。

范围只在前端结果页与共用详情组件；不新增接口、LLM 调用、数据库表、迁移或服务。

## 功能需求

### 视图外壳

- **F1 三视图外壳**：结果区由一个统一外壳承载「手册 / 地图 / 看板」三种视图，切换器常驻顶部，桌面与移动端位置一致。默认进入手册；同一次会话内记住上次选择，重新加载会话时回到手册。对话列、工具卡、决策卡、版本菜单、分享入口的位置与职责不变；桌面端右侧独立检查器不再存在，详情内容并入各视图。
- **F2 切换保持状态**：切换视图时保持当前天、选中点或选中路段、预算口径（含 / 不含住宿）与版本预览状态；不发起新的请求、不触发新的规划运行。滚动位置不逐像素保持，切回时回到该天顶部。
- **F3 分享页只读手册**：分享快照只呈现手册视图，不出现切换器、版本操作、运行轨迹或内部标识；快照允许字段与现有语义不变。

### 手册视图

- **F4 概览**：顶部依次给出方案标题、一句话路线摘要、天数、景点数、步行距离、预算与节奏；这些信息全部来自已有方案数据。
- **F5 每日章节**：每天一个章节，含日期与星期、当天主题、起止时间、当天花费；章节内按时间顺序给出停靠点、停留时长、单项花费与点间交通衔接，形成可连续阅读的段落，而不是并列色块；站间交通以高亮路线连接，每个章节配一张只画当天的路线小图。
- **F6 理由与来源**：每个停靠点就地展示「为什么选它」与相关攻略来源（含来源站点名）；解释或攻略缺失时显示明确说明，不允许空白。
- **F7 留白显式**：当天未安排的时间段必须显式标注为「未排」并给出可执行建议（如午饭、休息、取行李），不能以空白或跳过的形式出现。
- **F8 收尾信息**：每天末尾给出当天合计；全程末尾给出住宿摘要（名称、位置、单价、是否计入预算）与出发前提醒（闭馆、预约等已有提醒）。没有提醒时不显示该块。

### 地图视图

- **F9 每天单独成图**：地图一次只绘制一天，不提供多天叠加视图；每次进入地图视图都停在一个具体的天（默认第 1 天，或沿用选中点所在天），天切换中不出现「全部」。当天图显示编号标记、住宿锚点与当天路线；站间交通按出行方式高亮，选中某段时该段加粗、其余路线变淡；切换天时重新聚焦该天，不弹信息窗。
- **F10 剧本列**：地图旁按时间顺序列出当天停靠点与交通衔接，交通行显示方式、耗时与花费并可点选；每项含时间、时长、花费、理由与攻略来源；点击地图标记选中该点并同步剧本，点击剧本定位地图。
- **F11 地图降级**：地图不可用（无 Key、加载失败）时，地图位置替换为当天的可点击文字清单；手册中的当天小图同步降级为文字清单；选中仍同步共用详情，说明文字明确且不报错。

### 看板视图

- **F12 指标与分列**：顶部展示总预算、住宿、门票、步行、景点数；下方按天分列，每块给出时间、标题、花费与一句理由；每天列头显示当天合计。
- **F13 核对**：未排时段与出发前提醒在看板中可见；选中某块时浮出与手册、地图相同的详情内容，并提供调整入口。

### 共用能力

- **F14 共用详情与安全**：三种视图使用同一份详情内容与同一套措辞（理由、攻略来源、时长、花费、交通、外链）；交通段详情同样只此一份；外部链接只接受 http/https，新窗口打开且不传递 opener；事件与外部文本按纯文本渲染。
- **F15 调整入口**：调整这一天、预算含 / 不含住宿切换在三种视图中都可触达，调用既有接口；提交失败就地显示错误，不丢失当前输入或选中状态。
- **F16 移动端形态**：390px 下三种视图分别呈现为一天一屏（天切换吸顶）、当天全屏地图（可关闭回到原对话位置）、按天折叠清单；切换器不藏进二级菜单；三种形态均无横向溢出。
- **F17 降级与旧数据**：旧运行缺少解释、攻略、坐标或增补事件时，三种视图都不空白、不报错，按缺失项显示明确说明；插件关闭仍可完整阅读。
- **F18 交通高亮与路线详情**：地图与手册小图使用同一套路段样式（步行、公交、地铁、驾车可区分）；点击地图折线、手册/剧本/看板的交通行，打开同一份路段详情：出行方式、线路名、上车站与下车站、距离、耗时、花费、是否估算；有折线时按真实走向绘制并聚焦该段，无折线时明确标注为直线估算。手册小图提供「查看路线图」，切到地图视图并停留在该天。详情中的站点与线路名称按纯文本渲染，不含供应商原始响应。

## 非功能需求

- **N1 响应与性能**：切换视图在 100ms 内完成，不重新请求数据；单条运行事件到达后只更新受影响区域，不重建地图、不整页重渲染；4 天 × 8 块的行程在看板与手册中滚动、选中仍保持流畅。
- **N2 单一数据源**：三种视图、共用详情、预算与版本状态全部来自同一份推导结果；不允许任一视图自行缓存或重新计算，避免三处数字打架。
- **N3 可访问性**：正文对比度 ≥ 4.5:1，大字与图形 ≥ 3:1；不依赖颜色单独传达状态；仅用键盘可完成视图切换、选天、选点、展开详情、提交调整；焦点样式可见、顺序合理；对话与结果的变化以礼貌方式播报；支持 200% 文字缩放与减少动态效果。
- **N4 响应式**：覆盖 390 / 768 / 1024 / 1440 四档宽度；除地图内部平移外不出现横向滚动；加载骨架与最终布局尺寸一致，避免跳动。
- **N5 安全与隐私**：结果区不出现 API Key、请求头、供应商原始响应或内部堆栈；事件与外部文本按纯文本渲染；外部链接只接受 http/https，新窗口打开并设置 noopener；分享页只暴露快照允许字段。
- **N6 降级**：旧运行事件、旧版本方案、插件关闭、地图不可用、游客模式下，三种视图都可完整浏览并给出明确说明，不报错、不空白。
- **N7 边界不变**：不新增 LLM 调用、后端服务、消息队列、缓存组件、数据库表或迁移；不改变规划算法、认证、CORS、分享权限与快照语义；现有接口与事件字段语义保持不变。
- **N8 依赖与设计系统**：不引入新 UI 框架、浏览器状态库、图表库或地图库；颜色、字体、间距、圆角由现有 token 提供，金额使用等宽数字；不新增暗色模式、多语言或 PWA。
- **N9 文案一致**：同一信息在三种视图与分享页使用同一措辞与同一组件表现，例如「为什么选它」「未排」「含住宿」；中文文案、人民币金额、日期格式（如「11 月 20 日 周五」）全站统一。
- **N10 可测试性**：视图数据推导、预算口径、降级与缺失字段处理可用纯逻辑测试覆盖；端到端测试由固定事件样例与 mock 地图驱动，不依赖真实 LLM、真实地图 Key 或外部插件。

## 不做的事

- 不改对话列、工具卡、决策卡与叙事消息；本次只动结果区（桌面画布列、移动端方案面板）与分享页的结果呈现。
- 不新增第四种视图，不做拖拽排序、自定义布局或主题设置页。
- 不做打印 / PDF 导出、日历订阅、离线缓存。
- 不做多天叠加地图或跨天连线；每天只画自己当天的路线。
- 不做地图内嵌导航、逐步转向指令、实时定位、实时天气接入。
- 不做多城市、多目的地的数据模型扩展。
- 不跨设备同步视图偏好；只在本次会话内记忆。
- 不在分享页提供视图切换或任何编辑入口。
- 不新增后端接口、事件类型或数据库字段；不新增 LLM 调用来改写文案，解释与攻略一律使用已有数据。
- 不改变版本、分享权限、快照语义、认证与 CORS。
- 不新增手势交互（如左右滑动切天），切天与切换视图都使用可见控件。
- 不回填历史事件、不迁移历史方案 JSON。

## 验收标准

- **AC1 外壳与默认**：打开已完成方案，默认看到手册；顶部切换器在桌面与移动端位置一致，可切到地图与看板；刷新会话后回到手册。（F1）
- **AC2 状态保持**：在第 2 天选中一个点或一段交通后依次切换地图、看板再切回手册，天与选中对象不变；切换过程中没有新的数据请求或运行。（F2、N2）
- **AC3 分享只读**：分享链接只呈现手册，无切换器、版本操作或内部标识；工作台中的地图、看板不出现在分享页。（F3、N5）
- **AC4 概览**：手册顶部出现标题、一句话摘要、天数、景点数、步行距离、预算与节奏，数值与方案数据一致。（F4）
- **AC5 每日章节**：每天可按时间顺序读完停靠点、停留时长、单项花费与点间交通，并看到一张只画当天的路线小图；不再需要靠并行色块推断先后。（F5）
- **AC6 理由与来源**：每个停靠点就地可见理由与攻略站点名；缺少解释或攻略时显示明确说明而非空白。（F6）
- **AC7 留白**：方案中未安排的时段在手册与看板中显示「未排」及建议，不出现无说明的空白。（F7）
- **AC8 收尾**：每天显示当天合计；全程末尾显示住宿摘要与出发前提醒；无提醒时该块不出现。（F8）
- **AC9 每天单独成图**：地图视图中不存在多天叠加，任何时刻只显示一天；切天只显示该天标记、住宿锚点与路线；当天路线中的交通段按方式可区分，选中一段后该段加粗、其余变淡并聚焦该段；进入地图时落在具体某天；点击标记与点击剧本互相同步，不弹信息窗。（F9、F10）
- **AC10 地图降级**：断开地图后，地图视图出现当天的文字清单与明确说明，手册小图降级为文字清单，选点与选中交通段仍能打开共用详情。（F11、F18、N6）
- **AC11 看板**：顶部五项指标与预算拆分一致；每天一列且列头显示当天合计；块内可见时间、标题、花费与一句理由。（F12）
- **AC12 看板核对**：未排时段与出发前提醒在看板可见；点选某块浮出与手册相同的详情并可进入调整。（F13）
- **AC13 共用与安全**：三种视图中同一停靠点的理由、攻略、时长、花费、交通文案一致；`javascript:` 链接不渲染为可点击，http(s) 链接新窗口打开且不传递 opener；含 HTML 的文本按纯文本显示。（F14、N5）
- **AC14 调整与预算**：三种视图都能发起「调整这一天」与住宿口径切换；请求失败时就地显示错误，当前输入与选中状态不丢。（F15）
- **AC15 移动端**：390px 下三种视图分别为一天一屏、当天全屏地图、折叠清单；关闭地图面板回到原对话位置；全程无横向滚动。（F16、N4）
- **AC16 旧数据**：加载缺少解释、攻略、坐标的旧运行，三种视图均有降级说明且不报错；插件全关时仍可完整阅读。（F17、N6）
- **AC17 性能与一致性**：切换视图在 100ms 内完成且无新请求；任一视图中的预算、选中点、版本变化在其余视图立即一致。（N1、N2）
- **AC18 可访问性**：仅用键盘可完成切换视图、选天、选点、展开详情与提交调整；对比度达标；200% 缩放与减少动态效果下布局可用。（N3）
- **AC19 边界**：依赖、迁移目录、事件类型、认证与分享行为无新增或变更；构建与既有测试通过。（N7、N8、N9）
- **AC20 交通高亮与详情**：选中一段交通后，地图与手册小图都在同一位置高亮该段、其余路线变淡；详情显示方式、线路名、上/下车站、距离、耗时、花费与估算标记；有折线时按真实走向绘制，无折线时明确写「直线估算」；三种视图打开的是同一份内容；手册「查看路线图」切到地图并停在该天。（F18）
