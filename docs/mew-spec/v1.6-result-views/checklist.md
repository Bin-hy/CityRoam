- [ ] 页面刷新后回到手册，不记忆上次视图（验证：切到看板后刷新，观察默认视图）。
- [ ] 在第 2 天选中一个停靠点，依次切到地图、看板、再回手册，天与选中对象不变（验证：观察高亮与详情内容）。
- [ ] 整个切换过程没有新的数据请求或规划运行（验证：Network 面板无新请求，对话无新事件）。
- [ ] 地图视图不存在「全部」，进入时停留在具体某天（验证：检查天切换项与当前地图内容）。
- [ ] 手册中点选某天只显示该天，「全部」恢复所有章节（验证：切换天标签）。
- [ ] 对话中的跳转落到对应天与停靠点，移动端同时打开方案面板（验证：点击对话中的地点链接）。
- [ ] 版本预览下三种视图显示同一版本；「返回当前」恢复当前方案（验证：用版本菜单切换后逐视图比对）。

## 手册视图

- [ ] 顶部概览出现标题、一句话摘要、天数、景点数、步行距离、预算、节奏，数值与方案数据一致（验证：与预算弹层、方案原始数据核对）。
- [ ] 每天章节可按时间顺序连续读完停靠点、停留时长、单项花费与点间交通，而不是并列色块（验证：通读第 1 天）。
- [ ] 每个章节有一张只画当天的路线小图（验证：小图站点与当天行程一致，不含其他天）。
- [ ] 每个停靠点就地显示「为什么选它」与攻略来源站点名（验证：展开任意景点与餐饮）。
- [ ] 缺解释时显示「本次未生成额外说明」，缺攻略时显示「暂无攻略提及」（验证：加载旧数据样例）。
- [ ] 未安排时段显示「未排」并给出建议，不出现无说明空白（验证：选择有长空档的一天）。
- [ ] 每天末尾显示当天合计；全程末尾显示住宿摘要与出发前提醒；无提醒时不出现提醒块（验证：检查有/无提醒两种方案）。
- [ ] 选中停靠点后该行高亮，理由与来源就地可见，不弹浮层（验证：点击一个停靠点）。

## 地图视图

- [ ] 任何时刻只显示一天；切换天只显示该天标记、住宿锚点与路线（验证：逐天切换，观察无其他天标记与连线）。
- [ ] 当天交通按步行、公交、地铁、驾车可区分（验证：对照图例检查颜色与虚线）。
- [ ] 选中一段交通后，该段加粗、其余路线变淡，并聚焦该段（验证：点击地图折线或剧本交通行）。
- [ ] 点击地图标记选中该点并同步剧本高亮；点击剧本项定位地图（验证：双向各点一次）。
- [ ] 地图不弹信息窗（验证：点标记与折线，观察无 InfoWindow）。
- [ ] 点击折线打开路段详情，显示方式、线路名、上/下车站、距离、耗时、花费与估算标记（验证：选择带地铁分段的方案）。
- [ ] 有折线时按真实走向绘制；无折线时画直线并明确写「直线估算」；缺坐标时地图跳过该段（验证：分别用三种样例）。
- [ ] 图例只列出行方式、直线估算与 GCJ-02，不再列多天颜色（验证：查看地图下方图例）。
- [ ] 切换天后重新聚焦当天，不残留上一天的覆盖物（验证：连续切天观察地图）。

## 端到端场景

### 场景 1：桌面完整阅读与三视图往返

1. 打开一个已完成方案 → 默认手册，第一屏可见概览与第 1 天。
2. 切到第 2 天，选中一个景点 → 切地图 → 地图停在第 2 天且该点高亮。
3. 点击一段地铁折线 → 出现路段详情（线路、上下车站、耗时、花费）。
4. 切看板 → 选中块浮出同一详情 → 切回手册 → 天与选中仍在。
5. 期望：全程无新请求，文案一致，无布局跳动。

### 场景 2：交通路线专题

1. 打开含步行 + 地铁 + 步行分段的方案，进入手册。
2. 点击路段行 → 展开分段详情；点击「查看路线图」。
3. 期望：切到地图并停在该天，该段加粗、其余变淡，且聚焦该段；无折线样例显示「直线估算」。

### 场景 3：地图不可用

1. 使用未配置地图 Key 的环境打开方案，进入地图。
2. 期望：出现当天文字清单与说明；点停靠点与路段仍打开详情；手册小图同步降级为清单。

### 场景 4：390px 移动端

1. 从对话打开方案面板 → 手册一天一屏 → 切地图 → 全屏地图 → 关闭面板。
2. 期望：回到原对话位置；切换器始终可见；三种视图无横向滚动。

### 场景 5：分享与旧快照

1. 打开分享链接 → 只看到只读手册、小图与来源信息；Network 无 AMap。
2. 打开缺解释、攻略、坐标的旧快照 → 各缺失项有明确说明，不报错。

### 场景 6：调整与失败

1. 在手册点击「调整这一天」，输入框预填并聚焦；提交失败时观察错误位置。
2. 在工具栏切换住宿口径，构造失败。
3. 期望：错误就地显示，视图、天、选中与输入不丢。
