# TripPilot v1 MVP Spec

> 状态：已批准（2026-11-19）

## 背景

学生和年轻旅行者做北京短途旅行时，通常用通用聊天模型生成行程，但结果经常不可执行：景点周一闭馆、两个点之间来不及、预算超标、餐厅不在营业时间。用户也不知道模型依据是什么，改一句话往往要整份重来。

TripPilot 要解决的不是「生成一份看起来不错的行程」，而是「生成一份经过校验、能照着走、改得动、说得清依据的行程」。本版只做北京、1～4 天，单人使用，不涉及预订和支付。

## 目标

- 用户用一句话提出多约束需求，系统产出结构化、可执行的行程。
- 行程经过确定性校验；阻断项要么修复，要么明确告知。
- 每个安排能追溯到候选 POI、来源和校验结果。
- 用户用自然语言调整时，只改动受影响范围，并保留版本。
- 有 20 条固定评测用例和可复现的指标表。
- 6 周、约 60 小时内完成，可本地运行，可选公网演示。

## 外部依赖与准备清单

开始实现前需要准备以下凭证。除 PostgreSQL 外，其余都是外部 API。

| 依赖 | 用途 | 需要准备 | 是否必需 |
|---|---|---|---|
| LLM API | 需求解析、选点、修复、解释 | OpenAI 兼容的 Base URL、API Key、模型名 | 是 |
| 高德 Web 服务 API | POI 搜索、路径规划、地理编码、天气 | 「Web服务」类型 Key | 是 |
| 高德 JS API | 前端地图渲染 | 「Web端(JS API)」类型 Key + 安全密钥 | 是 |
| PostgreSQL 16 | 行程、版本、运行记录 | 本地 Docker 即可 | 是 |
| 域名 + VPS | 公网 demo | 可选 | 否 |
| 第三方搜索 / MCP | 小红书、网页搜索 | 可选 | 否 |

### 必须准备的 Key

**1. LLM API**

- 推荐 DeepSeek（OpenAI 兼容）：`LLM_BASE_URL=https://api.deepseek.com`，`LLM_MODEL=deepseek-chat`。
- 也可以用通义千问 DashScope 兼容模式或其他 OpenAI 兼容服务。
- 需要 API Key 和少量余额；20 条评测预计 10 元以内。
- 变量：`LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`。

**2. 高德 Web 服务 Key（服务端）**

- 在高德开放平台创建应用，添加「Web服务」类型 Key。
- 用于 POI 搜索、路径规划、地理编码、天气查询。
- 变量：`AMAP_WEB_KEY`。
- 只放在服务端，不能下发到浏览器。

**3. 高德 JS API Key + 安全密钥（前端）**

- 同一应用下再添加「Web端(JS API)」类型 Key，并生成安全密钥。
- 用于地图、标记、路线绘制。
- 变量：`VITE_AMAP_JS_KEY`、`VITE_AMAP_SECURITY_CODE`。
- 在高德控制台配置域名白名单：`localhost` 和实际部署域名。

**注意**

- 高德「Web服务」和「Web端(JS API)」是两个不同的 Key，不能混用。
- 提前完成开发者实名认证，并确认个人配额是否够 demo 使用。
- 所有 Key 只放本地 `.env` 或部署环境变量，不提交到仓库；仓库只提交 `.env.example`。
- 本版不接入小红书爬虫，避免条款和合规风险；MCP 只保留可选扩展位。

## 功能需求

- **F1 需求解析**：接收一句话输入，识别城市、天数、预算、兴趣、节奏、必去、不想去中的至少 4 类；城市或天数缺失时追问，不擅自假设；无法识别的信息进入待确认列表；解析结果可编辑。
- **F2 约束确认**：硬约束与软偏好分开展示；用户可修改任意字段，也可在硬/软之间切换；每次生成保留约束快照。
- **F3 候选检索**：按城市、兴趣、必去、日期检索 40～60 个候选 POI；必去点必须在候选集中；候选包含 ID、名称、类别、坐标、营业时间、门票、建议时长、评分、来源；同城同条件缓存 24 小时。
- **F4 行程草案**：模型只能从候选集中选点，输出每天的点位顺序、建议时长和开始提示；系统计算精确到访时间、交通块和费用；每天至少一个餐饮块，除非用户明确关闭；未知 POI ID 直接判非法；生成失败保留上一版。
- **F5 确定性校验**：校验营业时间、闭馆日、路程与缓冲、每日时长、预算、餐点窗口、必去点、重复 POI、节奏、起止时间、雨天户外比例、最短停留；每条违规包含类型、级别、涉及时间块和修复建议。
- **F6 自动修复**：有阻断项时只重排受影响的天或时间块；最多 3 轮；每轮重新校验；阻断清零、达到轮数、连续两轮无改善或用户取消时停止；停止后输出当前最优解、剩余违规和放宽建议。
- **F7 自然语言调整**：识别调整对象（某天、某块、某 POI、整体节奏、预算）；先输出调整提案，说明改什么、为什么、影响什么；用户接受才生成新版本，拒绝保留原版本；只改受影响范围；无法理解时追问。
- **F8 版本与差异**：每次生成、修复、调整都产生版本；版本包含行程、约束快照、违规记录和原因；支持任意两版差异、回退；超过 20 版提示清理。
- **F9 地图与时间轴**：地图按天展示路线并用颜色区分；时间轴与地图联动；显示交通方式、耗时、花费；移动端可读；地图加载失败时时间轴和文本仍可用。
- **F10 分享与导出**：生成无需登录的只读分享链接；分享页包含行程、预算、AI 生成标识和数据来源；支持复制纯文本；只展示最终版本；未分享的行程不公开。
- **F11 运行追踪与推送**：每次运行有唯一 ID；记录步骤、工具调用、模型调用、耗时、token、错误；通过 SSE 推送进度；断线后能续传；事件可回放。
- **F12 评测**：内置 20 条用例，覆盖 1～4 天、不同预算、不同节奏、必去、雨天、闭馆日；一键跑评测并输出指标表；失败用例可回放到具体步骤。

## 非功能需求

- **N1 性能**：需求解析 ≤5 秒；3 天行程端到端 p95 ≤60 秒；SSE 每 2 秒至少一次心跳。
- **N2 可靠性**：工具超时 10 秒、重试 2 次；模型超时 60 秒；单次运行最多 3 轮修复；服务重启后能从等待状态恢复。
- **N3 成本**：单次规划模型成本 ≤0.5 元；POI 和路径缓存复用。
- **N4 安全**：API Key 只在服务端；输入长度限制；按 IP 限流 10 次/小时；不采集身份信息；用户输入和外部内容不得作为系统指令执行。
- **N5 合规**：地图和 POI 数据遵守来源方条款；价格标注为估算；页面明确 AI 生成标识；不抓取未授权内容。
- **N6 可移植**：Docker Compose 一键启动；配置全部通过环境变量注入。
- **N7 可观测**：所有工具调用和模型调用可追踪；错误有分类；提供健康检查。
- **N8 可用性**：地图失败不阻塞主流程；加载、空结果、失败都有明确状态；移动端不依赖悬停。
- **N9 部署范围**：单地域、单节点、单实例；不做高可用和多租户。

## 不做的事

- 预订、支付、订单。
- 账号体系、多人协作、社区。
- 酒店、机票、跨城交通。
- 实时路况、排队时间。
- 原生 App。
- 图像、语音、视频生成。
- 多城市（P2）。
- PDF、日历导出（P1）。
- 分享页地图（P1）。
- 微服务、Redis、消息队列、K8s。
- 小红书爬虫或未授权数据抓取。
- 第三方 MCP 作为核心依赖；只保留可选扩展位。

## 验收标准

- **AC1**：输入「北京两天，预算800，喜欢历史和咖啡，不要太赶，周一出发」，能得到包含城市、天数、预算、兴趣、节奏的结构化约束和一份行程。
- **AC2**：输入缺少城市或天数时，系统停在等待状态并追问，不擅自补默认值。
- **AC3**：用户能修改硬/软约束；修改后旧版本保留，新版本使用新约束。
- **AC4**：候选集为 40～60 个 POI，必去点在集合内；模型输出未知 POI ID 时被拒绝并重试。
- **AC5**：草案包含每天起止时间、时间块、交通方式、费用；餐饮开启时每天至少一个餐饮块。
- **AC6**：C1～C12 均有独立校验和单元测试；违规项包含类型、级别、时间块、修复建议；20 条用例硬约束满足率 ≥90%。
- **AC7**：修复最多 3 轮；阻断清零后输出；3 轮后仍有阻断时输出最优解、剩余违规和放宽建议；不会无限循环。
- **AC8**：自然语言调整先给提案；接受后生成新版本，拒绝后保留原版本；未受影响的天不变；无法理解时追问。
- **AC9**：能查看任意两版差异并回退；版本包含行程、约束、违规和原因。
- **AC10**：地图按天展示路线，点击时间块能高亮地点；地图加载失败时时间轴和文本仍可用。
- **AC11**：分享链接无需登录、只读、带 AI 标识和来源；能复制纯文本；未分享行程不可访问。
- **AC12**：SSE 推送阶段、工具、校验和修复事件；断线后通过 Last-Event-ID 续传；事件落库可回放。
- **AC13**：20 条评测用例可一键运行，输出硬约束满足率、修复轮数、延迟、POI 有效率、JSON 合法率和人工评分；JSON 合法率 ≥99%；失败用例可回放。
- **AC14**：需求解析 ≤5 秒；3 天行程 p95 ≤60 秒；SSE 心跳间隔 ≤2 秒。
- **AC15**：模拟工具超时或服务重启后，任务仍能完成或恢复到等待状态。
- **AC16**：`docker compose up` 可启动；README 能让陌生人在 10 分钟内跑通；仓库无密钥；IP 限流生效。
- **AC17**：单次规划模型成本 ≤0.5 元。
