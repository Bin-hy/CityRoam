# TripPilot v1.2 体验修复 Spec

状态：待审批（spec）
日期：2026-11-20

## 背景

v1.1 已具备酒店与攻略研究能力，但四个环节让用户体验断裂：

1. 两个插件默认关闭，且 `/api/meta` 因插件名称映射错误，始终报告「未启用」且没有原因；即使手动开启，界面仍可能显示未启用。
2. 「拒绝」是终态：用户对方案不满意只能取消本次运行，改稿能力只对已接受版本开放。
3. 酒店锚点只认研究模型给出的住宿选择与锚定天数；用户在需求里点名的酒店不会进入排期几何，行程从第一个景点开始。
4. 地图只有一条连接景点坐标的直线：后端丢弃了路径服务返回的分段几何，数据结构里也没有折线字段。

当前运行环境可以作为基线：酒店 sidecar 在 8090 健康运行，API 以插件关闭状态启动，攻略 key 为空。

## 术语

- **锚定**：把酒店作为当天行程的起点和终点，在时间轴上生成「从酒店出发」与「返回酒店」两个交通段。
- **分段几何**：一条交通由若干 leg 组成，例如步行到地铁站、乘坐某线路、出站步行到景点；每个 leg 带方式、时长、费用、线路名、上下车点和折线坐标。
- **拒绝即修改**：用户对当前方案不满意时，直接说明不满并生成新的调整提案，而不是终止本次运行。
- **降级**：外部依赖不可用或超时时，主链继续运行，界面明确说明缺失原因，不伪造数据。

## 目标

- G1：插件启用状态与禁用原因如实展示；按开关即可启用酒店（FlyAI sidecar）与攻略（DeepSeek WebSearch）。
- G2：拒绝不再终止对话。用户可直接说明不满，系统基于当前版本生成新的调整提案，形成「生成→反馈→再生成」闭环。
- G3：用户点名的酒店在可解析时成为每天默认起终点；不可解析时停下追问，不静默忽略。
- G4：地图展示分段通行方案（步行、公交、地铁、打车；含线路名与上下车点），按方式区分渲染。
- G5：保持既有语义不变——闭集选点、C1–C12 校验、事件回放、20 条 v1 评测基线不被破坏。

## 功能需求

### A. 插件可用性与状态

- **F1 启用判定**：酒店插件在开关开启且 sidecar 健康探测通过时可用；攻略插件在开关开启且搜索 key 非空时可用。任一条件不满足即禁用，并给出稳定、可读的禁用原因。
- **F2 状态如实展示**：研究面板与 `/api/meta` 必须正确反映实际启用状态与原因；插件启用时不得再显示「未启用」。
- **F3 降级不阻断**：插件不可用、搜索超时或结果为空时，行程仍能生成；界面显示降级原因，不伪造住宿或攻略内容。

### B. 拒绝即转修改

- **F4 拒绝进入修改**：初始方案在等待确认时点「拒绝」，原地出现反馈输入框，运行不终止；提交后基于当前草稿版本创建一个调整提案。
- **F5 提案拒绝后的落点**：调整提案被拒绝时，保留当前版本并回到可继续反馈的状态，而不是进入取消终态。
- **F6 反馈约束**：反馈必须非空，长度上限沿用 2000 字符；空白或超长提交被拒绝并提示。
- **F7 显式取消仍保留**：用户主动取消时运行进入取消终态；「拒绝」不再等同于取消。
- **F8 改稿失败可恢复**：调整运行失败时，原版本保持可用，用户可直接再次提交反馈。

### C. 酒店锚定

- **F9 解析优先级**：酒店工具结果 → 地理编码 → 追问用户；多个候选或无法唯一定位时追问，不得编造酒店。
- **F10 默认锚定策略**：用户点名酒店且解析成功时，默认每天从酒店出发并返回酒店；用户明确只住某几天时只锚定对应天。
- **F11 价格缺失处理**：仅有地理编码、没有房价时，标注「住宿费用未计入」，不得虚构价格，也不得把住宿费计入预算。
- **F12 锚点可见**：方案中第一个交通段为「从酒店出发」、最后为「返回酒店」；时间轴与地图显示酒店名称和位置。
- **F13 无插件也可锚定**：只配置地理编码能力时，点名酒店仍可锚定；地理编码也不可用时明确警告或追问，不静默忽略。
- **F14 预算口径**：有可信房价且用户预算包含住宿时，按 N-1 晚计入；价格未知时不计入并给出警告。

### D. 地图分段路线

- **F15 分段几何**：每条交通生成按 leg 描述的数据：方式、时长、费用、距离、线路名（公交/地铁）、上下车点、折线坐标（抽稀并限制点数）。
- **F16 分段渲染**：地图按天、按 leg 绘制路线，不同方式使用可区分样式；同时绘制兴趣点与酒店标记，并与时间轴选中联动。
- **F17 快照一致**：几何随版本快照存储，刷新、回放与导出保持一致，不依赖前端重新求路。
- **F18 几何缺失降级**：路径服务超时、超额或无路线时回退直线估算，明确标注「估算」，不冒充完整路线。

## 非功能需求

- **N1 契约兼容**：HTTP/OpenAPI 只做向后兼容扩展；「拒绝」语义变更的同时保留显式取消；旧版本快照（无分段几何）必须仍能展示，降级为直线。
- **N2 性能**：新增几何解析不增加路径服务求路调用次数（仅酒店地理编码至多 2 次）；排期 p95 增幅不超过 10%；模型主链耗时不变。
- **N3 数据上限**：单条 leg 折线抽稀到 ≤60 个点，单日 ≤600 个点，单个版本快照体积增幅 ≤100KB；超出时继续抽稀而不是截断路径。
- **N4 失败降级**：地理编码、路径几何、攻略搜索任一失败都不得阻断主链；几何缺失回退直线并标记为估算，酒店无法定位则追问。
- **N5 可回放**：所有新增数据必须可序列化并写入版本快照；刷新、事件回放、导出看到同一份几何。
- **N6 安全与隐私**：外部服务 key 仅在服务端使用；酒店名与地址只发送给地图服务；用户输入沿用现有长度限制；外部攻略内容继续按不可信处理。
- **N7 可观测**：解析、降级、拒绝改稿等新路径发布可回放事件或日志，至少包含运行标识与原因码；不记录完整用户输入。
- **N8 配置兼容**：不新增必需环境变量；旧环境文件不改也能启动，新能力缺配置时降级并给出原因。
- **N9 数据迁移**：几何与酒店锚点放在既有快照内，原则上不新增表；确需迁移时走现有迁移工具并可回滚。
- **N10 测试基线**：后端单测、前端单元测试、端到端测试全绿；现有 20 条 v1 评测用例与 v1.1 插件评测不回退；新增行为有对应测试。
- **N11 部署约束**：仍为单机 2C4G、Docker Compose，不引入新中间件。

## 不做的事

- 不引入新的搜索供应商，不抓取小红书全文；小红书搜索为空记录为已知限制。
- 不做实时路况、实时公交到站或逐向导航。
- 不做多城市与跨城交通。
- 不做酒店预订、支付。
- 不做分享页地图（仍为 P1）。
- 不引入 Redis、消息队列或拆分服务。

## 假设与依赖

- 酒店插件依赖本机或 Compose 内网的 FlyAI sidecar；不可用时按降级规则处理。
- 地理编码与分段几何依赖地图 Web 服务 key；缺失时按降级规则处理。
- 攻略插件依赖搜索 key；供应商暂时不变，返回空视为降级而非失败。

## 验收标准

### 插件

- **AC1** 酒店开关为 true 且 sidecar 健康时，`/api/meta` 返回 `hotels.enabled=true`，研究面板不再提示未启用；关闭时返回 false 并给出可读原因。
- **AC2** 攻略开关为 true、key 为空时返回 false 且原因包含缺失项；补上 key 重启后变为 true。
- **AC3** 攻略超时或空结果时，行程仍生成，页面显示降级原因，且不存在编造的住宿或攻略内容。

### 改稿闭环

- **AC4** 在等待确认时点「拒绝」出现反馈框，运行不进入取消终态；提交非空反馈后产生新的调整提案；接受提案生成新版本。
- **AC5** 拒绝调整提案后，保留上一版本并仍可继续输入反馈，状态保持可交互。
- **AC6** 空白或超长反馈被拒绝并提示，不产生新运行。
- **AC7** 显式取消仍进入取消终态并产生对应取消事件。
- **AC8** 模拟调整运行失败时，原版本仍可查看，可直接再次提交反馈。

### 酒店锚定

- **AC9** 点名酒店且酒店工具命中时使用其价格；插件关闭但配置地图 key 时用地理编码锚定；两者都不可用时追问，不静默继续。
- **AC10** 两天行程点名酒店后，每天首段为「从酒店出发」、末段为「返回酒店」，地图与时间轴显示酒店名称与位置。
- **AC11** 用户明确「只住第 1 天」时，仅第 1 天锚定。
- **AC12** 仅地理编码、无房价时，预算不含住宿且出现「住宿费用未计入」警告。
- **AC13** 有可信房价且预算包含住宿时，按 N-1 晚计入，预算口径切换仍可用。

### 地图路线

- **AC14** 接受版本的快照中，每条交通包含 leg 列表（方式、线路名、上下车点、时长费用、折线坐标），点数满足数据上限。
- **AC15** 地图按 leg 区分样式渲染；刷新与回放看到同一路线；点击标记同步时间轴。
- **AC16** 无几何的旧版本快照仍能渲染为直线，不报错。
- **AC17** 模拟路径服务超时，路线回退直线并标注估算。

### 回归与约束

- **AC18** 后端单测、前端单元测试、端到端测试全绿；20 条 v1 评测与 v1.1 插件评测不回退。
- **AC19** 单版本快照体积增幅 ≤100KB，排期 p95 增幅 ≤10%（以现有评测报告为基线）。
- **AC20** 沿用旧环境文件可直接启动，缺失新能力配置时降级并给出原因。
