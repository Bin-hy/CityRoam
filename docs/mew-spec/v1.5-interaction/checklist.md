## 验收前置

- [ ] P1 基线可运行：`go test ./...`、`cd web && npm test`、`cd web && npm run build` 均通过；记录初始结果。
- [ ] P2 准备固定事件样例：包含工具卡查询/预览/缓存/重试、研究降级、校验、修复、提案、完成；另备一份缺少全部增补字段的旧运行样例。
- [ ] P3 准备降级环境：无地图 Key、插件全部关闭、旧版本方案（无 explanations/无 research）。
- [ ] P4 启动独立后端与前端实例用于验收，不重启用户已有的 8080 进程；记录实际端口。
- [ ] P5 准备浏览器：Chrome/Safari 最近两个大版本；可用时补测 Firefox、Edge、iOS Safari 16+。
- [ ] P6 准备检查工具：浏览器 DevTools（Network/Performance/React Profiler）、对比度检查器、系统读屏（VoiceOver）、200% 缩放与减少动态效果开关。

## A 实现完整性：创建、对话与决策

- [ ] A1 创建页以一个自然语言输入框为主入口；示例需求可一键填入；提交后立即进入该行程工作台，对话出现用户消息；解析完成后出现约束标签；提交失败时停留原页且输入不丢失。（验证：浏览器走创建流程，分别制造成功与失败）
- [ ] A2 运行中刷新页面，对话按已持久化事件恢复，不重复、不乱序；阶段消息数量与阶段数一致，不按单条技术事件刷屏。（验证：等待一次运行出现多个阶段后刷新，对比刷新前后消息）
- [ ] A3 校验失败或修复发生时，对话出现可读说明；点击说明可跳转到画布并选中对应天或点。（验证：用固定校验失败样例运行，观察对话与画布）
- [ ] A4 工具卡折叠态含工具名称、查询摘要、状态、耗时、结果数；展开态含不超过 3 条结果预览，以及缓存/重试/并发标记；同一工具多次调用各自成卡。（验证：插件开启运行一次，展开酒店/攻略/天气卡）
- [ ] A5 工具失败或研究降级时，卡片显示原因与影响；方案仍能生成或明确告知影响；界面不出现错误页或空白。（验证：用失败/降级事件样例驱动）
- [ ] A6 缺少城市或天数时出现「补充信息」卡，仅询问缺失字段；提交后卡片折叠为摘要，Agent 继续；输入框直接文字回答也能继续。（验证：两种补充方式各走一次）
- [ ] A7 需要选住宿时出现候选卡，含名称、地址、价格/晚、评分、预订链接；选择后卡片折叠、地图出现住宿锚点、预算计入住宿；选择「不计住宿」后预算不含住宿。（验证：分别选择候选与不计住宿）
- [ ] A8 接受提案生成新版本并更新画布、对话出现结果消息；拒绝后进入修改输入态，再次提交在同一回合继续并产生新提案。（验证：完整走接受与拒绝两条路径）
- [ ] A9 同一时刻最多一张待操作卡展开；已处理卡只保留摘要；状态变化不再整卡替换原有操作区。（验证：连续触发补充、住宿、确认，观察卡片位置与展开数量）
- [ ] A10 已完成行程上提出调整后，产生新的调整回合与提案卡；接受后画布更新，拒绝后在同一回合继续修改。（验证：在已完成方案上提交调整）
- [ ] A11 用户可从对话回看本次会话的原始输入与约束解析结果；更早历史由版本入口承载。（验证：运行后滚动对话并打开版本菜单）
- [ ] A12 已登录用户可从历史列表返回任意行程，恢复到最近一次运行的对话；游客模式保持可用。（验证：登录/游客两种身份各走一次）
- [ ] A13 选中景点/餐饮时，检查器显示时间、时长、花费、交通衔接、「为什么选它」与相关攻略来源；解释缺失时显示明确说明，不空白。（验证：分别用含解释与无解释样例）
- [ ] A14 相同事件序列得到相同对话：同一固定样例连续推导两次，消息类型、顺序与文案一致；重复或乱序输入不产生重复消息。（验证：运行对话模型单元测试 + 手工比较两次结果）
- [ ] A15 对话文案不出现 `run_id`、`seq`、`blocking` 等内部术语；技术细节只在可展开的「详情」中出现。（验证：通读可见文案并搜索页面文本）

## B 画布：地图、时间轴、检查器

- [ ] B1 画布包含行程标题与状态、按天切换（全部/第 N 天，含日期与当天花费）、地图、时间轴、检查器、预算摘要、版本入口、分享入口。（验证：桌面端打开已完成方案）
- [ ] B2 地图按天着色并显示编号标记、住宿标记与路线折线；当前天强调；点击标记选中该点并同步时间轴与检查器；切换天时地图聚焦该天；地图不弹出 InfoWindow。（验证：逐天切换并点击标记）
- [ ] B3 时间轴按天分组，显示时间、类型、标题与花费；与地图双向同步；桌面端可缩放和平移。（验证：地图选点后看时间轴，再点时间轴块看地图）
- [ ] B4 检查器未选中时给出引导；选中后信息完整；攻略外链以新窗口打开且不传递 opener；地图与时间轴选中变化只更新高亮，不重建时间轴数据。（验证：选中前后对比 + 外链检查）
- [ ] B5 运行中草稿到达时，画布显示「草稿预览」；最终确认后标识消失并转为正式版本。（验证：观察草稿与确认两个时刻）
- [ ] B6 预算摘要显示总计；展开可看门票、餐饮、交通、住宿拆分与估算提示；切换是否含住宿触发新的调整回合；只读分享视图不显示切换。（验证：桌面工作台与分享页各看一次）
- [ ] B7 版本菜单显示版本号、时间、变更原因；选择历史版本可查看新增/移动/删除差异；可回退；回退后画布更新，对话出现结果或系统提示。（验证：选旧版本 → 看差异 → 恢复）
- [ ] B8 分享入口保留生成与复制链接能力；权限模型与快照语义不变。（验证：生成链接并复制，游客打开）
- [ ] B9 小屏「查看方案」以全屏面板打开，内含按天切换、地图/时间轴切换与检查器；关闭后回到对话原位置。（验证：390px 宽度操作）
- [ ] B10 无地图 Key 时显示明确说明与按天分组的可点击文字清单；清单选点仍同步检查器。（验证：移除 Key 后加载）
- [ ] B11 旧运行缺少 explanations、research 或增补事件时，画布与检查器按降级说明显示，不空白、不报错。（验证：加载旧版本快照）
- [ ] B12 运行中刷新后画布恢复当前草稿或最近正式版本；选择历史版本后画布立即切换，刷新仍以正式版本状态为准。（验证：刷新前后对比）

## C 页面与视觉一致性

- [ ] C1 创建页为编辑感布局：单输入框、示例、偏好标签按需打开；大片常驻表单不再出现；窄屏纵向排列。（验证：1440 与 390 各看一次）
- [ ] C2 分享页为只读叙事：标题区（城市、天数、总预算、AI 生成标识）→ 地图与时间轴 → 选中点详情（含理由与攻略来源）→ 住宿与攻略摘要 → 预算摘要；不出现运行轨迹、版本操作或内部信息。（验证：打开分享链接逐段检查）
- [ ] C3 工作台对话列与画布列有明确主次；页面无 trip id 等内部标识；加载、空、错误、断线状态与最终布局一致，不以无限转圈作为主要进度表达。（验证：分别制造加载/空/错误/断线）
- [ ] C4 登录、历史列表、评测面板使用同一套颜色、字体与间距 token；评测面板信息结构与功能不变。（验证：逐页对照并操作评测面板）
- [ ] C5 同一信息在不同页面使用同一组件与同一措辞，例如「为什么选它」「估算」「不计住宿」。（验证：工作台、分享页、预算浮层对照）
- [ ] C6 中文文案统一；金额为人民币并使用等宽数字；日期格式一致（如「11 月 21 日 周六」）。（验证：抽查时间轴、预算、版本、分享页）

## D 事件与后端增补

- [ ] D1 工具调用事件增加人类可读查询摘要、结果预览（≤3 条）、缓存/重试/并发标记；不新增事件类型，既有字段语义不变。（验证：抓取 SSE 或查看固定事件样例）
- [ ] D2 酒店、攻略、天气三类工具都能生成查询摘要与结果预览；预览只含分享安全字段，不含 URL、令牌或原始响应。（验证：插件分别开启运行一次）
- [ ] D3 工具失败事件包含查询摘要但不含结果预览；失败原因可读，不影响后续事件顺序。（验证：用失败样例驱动）
- [ ] D4 校验事件包含已检查项数；无天气时为 12，有天气时为 13；`blocking/warnings/violations` 字段不变。（验证：运行校验单元测试与两种运行样例）
- [ ] D5 版本落库的方案 JSON 内嵌逐点解释；旧版本 JSON 仍可解析；无需数据库迁移。（验证：生成新版本 → 读版本接口 → 加载旧版本）
- [ ] D6 预览单条事件新增内容不超过约 2KB；对话、工具卡与分享页不出现 API Key、供应商原始响应、请求头或内部堆栈。（验证：检查事件大小与页面文本）
- [ ] D7 不新增 LLM 调用、后端服务、消息队列、缓存组件、数据库表或迁移；单实例 SSE 与现有部署方式不变。（验证：检查依赖、迁移目录与运行日志）
- [ ] D8 断线重连后从已持久化事件继续，客户端从 seq 0 重放并按 seq 去重；不重复、不丢序。（验证：断网约 10 秒再恢复）

## E 集成

- [ ] E1 新前端消费工具卡增补字段、校验计数与版本内解释；字段缺失时自动降级，不抛异常。（验证：新/旧两套事件样例各渲染一次）
- [ ] E2 创建 → 运行 → 接受提案后，画布更新且版本列表出现新版本；刷新后仍能看到。（验证：浏览器完整走一次）

- [ ] E4 版本恢复后，画布切换到恢复版本；对话出现结果或系统提示；刷新后以正式版本状态为准。（验证：恢复后立即检查与刷新后检查）
- [ ] E5 分享页只暴露快照允许字段；研究工作台中的运行轨迹、内部事件、版本操作不进入分享视图。（验证：对比工作台与分享页文本）
- [ ] E6 补充、修改、接受、拒绝、取消、住宿选择、调整、预算重算都能从界面触发并调用既有接口；失败时就地显示错误且不丢输入。（验证：逐动作操作，必要时用网络面板确认）
- [ ] E7 旧组件移除后无残留引用；前端构建与全部测试通过；`MissingFieldsForm`、纯文本导出、版本差异模型等仍在被使用。（验证：构建 + 搜索 + 测试）

- [ ] E9 工具卡、确认卡、检查器、版本菜单在 390px 下不横向溢出；内容可纵向滚动，关键信息不截断。（验证：390px 宽度逐项检查）
